# README — SMARTBUDGET MANAGER

**Prepared by Mahdi Anes | Group: [03]**

## What it does

Tracks monthly income and expenses, calculates totals and balance, summarizes category spending against budgets, displays an expense chart, and indicates budget status.

## Workbook sheets

- **Dashboard:** totals, balance, category summary, chart and status.
- **Transactions:** enter date, description, type, category, income OR expense, and notes.
- **Categories:** predefined categories and monthly budgets.

## Requirements

Microsoft Excel 2016/2019/2021, Microsoft 365, or a compatible spreadsheet application; the supplied .xlsx file; basic spreadsheet data entry.

## Get started

1. Make a working copy.
2. Open Transactions.
3. Enter a date, description, Type, Category, and an amount in Income OR Expense.
4. Leave the calculated Month column unchanged.
5. Open Dashboard to verify totals and status.
6. Review/edit budgets on Categories if needed.
7. Save your copy.

## Important

The Type column has a dropdown; the supplied file does not configure a Category dropdown, so enter category names consistently. Do not overwrite formulas.

Current sample values:
- Income: 1,800.00
- Expenses: 233.50
- Balance: 1,566.50
- Total budget: 1,270.00
